# Conceptos generales

- Orden creciente: Indica que el orden de los elementos es estrictamente creciente (1, 2, 4, 66, etc).

- Orden decreciente: Indica que el orden de los elementos es estrictamente decreciente (5, 3, 1, 0, etc).

- Orden no decreciente: Indica que el orden de los elementos es creciente, pero no necesariamente estrictamente (1, 2, 2, 3, 3, 3, 4, etc), es decir que permite valores duplicados y deben estar contiguos.

- Orden no creciente: Indica que el orden de los elementos es decreciente, pero no necesariamente estrictamente (5, 4, 4, 3, 3, 3, 2, etc), es decir que permite valores duplicados y deben estar contiguos.


- Nodo cabeza: Es el primer nodo de la lista.

- Nodo cola: Es el último nodo de la lista.

- Lista enlazada (linked list): Es una colección de nodos donde cada nodo contiene un valor y un puntero al siguiente nodo.

- Puntero "next" (siguiente): Es un puntero que apunta al siguiente nodo de la lista.

- Árbol binario (binary tree): Es una estructura de datos donde cada nodo tiene como máximo dos hijos.

- Árbol N-ario (n-ary tree): Es una estructura de datos donde cada nodo tiene como máximo N hijos.
  
- Nodo raíz: Es el primer nodo del árbol.

- Nodo hijo: Es un nodo que está conectado a otro nodo.

- Nodo padre: Es un nodo que tiene hijos.

- Nodo hoja: Es un nodo que no tiene hijos.

- Grafos (graphs): Son estructuras de datos compuestas por nodos y aristas que conectan a los nodos.
